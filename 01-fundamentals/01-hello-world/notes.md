When we write a Java program:

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello World!");
    }
}

```

We are not directly executing that source file. Instead, the execution roadmap looks like this:

```text
 Main.java
    │
    │ javac (Compiler)
    ▼
 Main.class
    │
    │ JVM (Java Virtual Machine)
    ▼
 Running Program

```

This process relies on three fundamental concepts:

* **Java Development Kit (JDK):** The software toolkit you install to develop Java applications. It contains, among other things, the necessary tools to compile and execute your code.
* **Java Virtual Machine (JVM):** The runtime environment that actually executes the Java bytecode.
* **Bytecode:** The intermediate code generated by the compiler. The compiler transforms the `.java` source file into a `.class` file, which contains bytecode destined for the JVM.

This architecture is the reason Java is famous for its core principle:

> Write once, run anywhere.

Because the source code is compiled into universal bytecode rather than machine-specific code, the compiled program can be executed on any operating system, provided it has a compatible JVM installed.
